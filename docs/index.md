# Client Demo Hub

This repository is a portfolio of client-facing website and admin dashboard demos. The live GitHub Pages site is assembled from the project folders at the repository root.

The deployment catalog is generated automatically. A project is included when its folder contains an `index.html` file at the root or inside a conventional frontend directory such as `web/`, `dist/`, `build/`, or `admin/`.

The generated catalog provides a home page and one button per discovered project. Each button opens the project's frontend entry point while keeping its relative CSS, JavaScript, image, font, JSON, TypeScript, SQL, and other files in the same folder structure.
